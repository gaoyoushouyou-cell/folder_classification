# ひきだし堂

散らかったフォルダを預かり、依頼主の要求書どおりに整えて報酬をもらうブラウザゲームです。
依存ライブラリはありません。

## 遊び方

`index.html` をブラウザで開きます。サーバーを立てる場合は次のとおりです。

```bash
python -m http.server 8765
```

進捗はブラウザの localStorage に保存されます。

## 依頼の種類

- **チュートリアル（修業）**: 手ほどきつきの 8 つの修業。上から順に進め、ひとつにつき 2〜3 個のことを身につけます。
- **飛び込みの依頼**: 店の格（1〜24）に合わせて自動で届きます。納めると格が上がります。
- **事情のある依頼**: 調査が入る、担当が辞めた、締め切りが迫るなど、依頼主の事情から決まりが生まれます。格は決まりどうしがファイルを取り合う度合いから測り、5 つの傾向（守り・外向き・限り・履歴・辿り）で表します。
- **広告**: お金を払って、好きな格の依頼を呼び込みます。合格すれば必ず広告費を上回ります。
- **稽古**: 格と件数を指定してまとめて作ります。報酬は三割です。

格が上がると増えるのはファイルの数ではなく、決まりごと（例外・クラウド・バックアップ・近道・鍵つきの金庫など）の数と掛け合わせです。

## 高い格で加わるもの

- **手数の上限**: 「1 つずつ運ぶ目安」と「道具をすべて使った理論値」のあいだに置かれ、格が上がるほど理論値に近づきます。高い格は道具が必須です。
- **通報**: 機密をクラウドに置くと、低い格では納品のときに差し戻し、格 13 からは警告のあと、すぐ直さないか二度目でその場で失敗します。
- **番号づけ**（格 21）: 棚は名前順に並びます。決まった順に並べるには、フォルダの頭に「01_」と番号を振ります。
- **名づけ直し**（格 22）: 中身の分からない名前のファイルを、札を見て決まった形に付け直します。元の名前と履歴は札に残ります。
- **封のかかった札**（格 23）と**施錠**（格 24）: 合言葉は「控え」のメモから控え帳に写して使います。
- **奥にしまう**（事情のある依頼）: 人目につかせたくないファイルを、指定された名前のフォルダを何段もたどった奥に置きます。

## 構成

| ファイル | 役割 |
|---|---|
| `js/core.js` | 名前空間、イベントバス、小道具 |
| `js/model.js` | 作業棚（フォルダとファイルの木構造）と、それを変える命令 |
| `js/evaluator.js` | 要求書の条項と、充足度・報酬の採点 |
| `js/levels.js` | 手づくりの依頼 |
| `js/generator.js` | 依頼の自動生成（格ごとの要素） |
| `js/progress.js` | 所持金・道具・成績の保存 |
| `js/tools.js` | 報酬で買う道具 |
| `js/ui.js` | 画面 |

## 拡張するとき

- 依頼を足す: `js/levels.js` の配列に 1 件足す
- 条項の型を足す: `js/evaluator.js` の `G.constraints.register`
- 自動生成の要素を足す: `js/generator.js` の `MECHS`
- 道具を足す: `js/tools.js` の `G.tools.register`

画面も道具も、棚を変えるときは `js/model.js` の命令を通します。手数の計上・ひとつ戻す・評価が、どの経路でも同じように働きます。
